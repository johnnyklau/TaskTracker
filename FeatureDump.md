# Future Features Planning

## Front End:
- I want to add more front-end technologies like Tailwind and Motion and get some more practice using them to develop with.
- Front end should be more of a idea dump / tasks dump with no due date
    - ex: Clean up my room, Make a call
- VISION: Make it a library/bookshelf like UI. Ideas will create books and put them onto the bookshelf.

## Back End:
- I want to update the existing Tasks to have a notes section in case I want to dump in any text alongside a task
- Tasks should also include chores, and an interval for it
- I should also be able to schedule chores on specific days (such as garbage collection)

## Mobile:
- I want to take the existing backend and connect it to a Swift mobile app
- Chores should have a widget so that I can see what chores I have to do today without opening the app
- Mobile app is more of a scheduled task tracker that can send notifications
    - ex: Garbage collection, Water flowers, Clean the cat litter
